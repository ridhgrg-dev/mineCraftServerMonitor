# Paper foundation

Java 25, Paper API 26.2 build 124 stable and pinned Gradle wrapper. The plugin logs enable/disable lifecycle and exposes resolved metadata. No network, game events or telemetry yet. Run `./gradlew spotlessCheck test build`; the built JAR contains the standard documented `plugin.yml` entrypoint. A live Paper load test is distinct from artifact compilation and must be recorded explicitly in phase results.
